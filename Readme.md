# Backend Cohort - Day-wise Projects

This repository contains Express.js assignments for the **Backend Cohort**.

## Folder Structure

- **Day1/**: Basic Express server
- **Day2/**: Express routes (`/`, `/home`, `/about`)
- **Day3/**: Notes API (`POST /notes`, `GET /notes`)

## How to Run (Per Day)

1. Go to the required day folder, for example:
   ```bash
   cd Day3
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the server:
   ```bash
   npm run dev
   ```

> Note: Each day runs on **port 3000**.
